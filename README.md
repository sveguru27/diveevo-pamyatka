# Памятка паломника: Дивеево, 24–28 сентября

Готовый статический сайт для GitHub Pages. Файлы `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` и `.nojekyll` должны лежать в **корне репозитория**. Сборка и зависимости не нужны.

## Задача для публикации

1. Создать публичный репозиторий в GitHub пользователя `sveguru27`, например `diveevo-pamyatka`, или использовать явно выбранный пользователем репозиторий.
2. Загрузить файлы из этого архива в корень ветки `main`. README можно также оставить в корне.
3. В `Settings → Pages` выбрать `Deploy from a branch`, ветку `main` и папку `/ (root)`; дождаться публикации по HTTPS.
4. Открыть опубликованную ссылку, проверить вкладки 24–28 сентября, молитвы, номера телефонов, поле имени и отзыв. Кнопка отзыва открывает Telegram с черновиком; **не отправлять пробный отзыв Екатерине**.
5. Попросить Светлану проверить ссылку на телефоне в России **без VPN** до рассылки группе. Доступность `github.io` в её сети заранее не гарантирована.
6. На телефоне один раз открыть сайт с интернетом, затем проверить вкладки в авиарежиме. При обновлениях сайта менять имя кэша в `sw.js` (`diveevo-v11` → следующее значение), чтобы офлайн-версия обновилась.

Все внутренние пути относительные, поэтому сайт работает и по адресу вида `https://имя.github.io/репозиторий/`. Публичный репозиторий будет содержать программу поездки, адрес гостевого дома и телефоны организаторов, которые уже включены в опубликованную памятку.
